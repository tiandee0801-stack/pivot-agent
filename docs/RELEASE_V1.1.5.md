# Pivot 换场 V1.1.5 功能快照

本版包括 54 个篮球体能动作、三套场景模板、可恢复的训练进度，以及记球后调整下一次训练的流程。现有预览的兼容版本标识仍为 `1.1.3`。

## 验收范围

1. 新访客先记录 52 分钟篮球，再保存健身房模板。发起调整时能看到并打开同一条篮球记录。
2. 昨天打球偏累，今天有 25 分钟。系统先确认今天的状态。确认正常后比较动作方案，确认前保留当前计划，确认后按保存的同一版本开练。仍偏累且缺合适方案时，可保留安排或预览改期。
3. 从「球场脚步与制动」逐项打开五个视频，检查播放和拖动。模板示范覆盖为居家 5/6、健身房 3/5、球场 5/5。球场自制动画待体能教练审核。 [示范来源](../web/assets/demos/SOURCES.md)
