# Pivot 换场｜手机端前端说明

V1.1.2 沿用 HTML、CSS、JavaScript 和同源 JSON API。深色手机端由 `refresh.css` 统一主题、状态、焦点和触控区。计划、训练、设备、历史、我的沿用原有路由。当前体验用深石墨背景与蓝紫主动作，训练页使用播放和人工校正区域呈现观察结果。

## 手机端主流程

- 「计划」展示已确认计划、可用时间、近期球局和三个快捷调整入口。说明变化后比较原计划、候选条件、结果与球局影响。
- 自然语言和追问答复提交后显示「正在整理你的条件」。最新结果的处理来源取自服务端 `activeTask.interpretation.source`，在本轮候选、追问或停止结果旁展示。规则降级时保留输入并沿本轮结果继续。缺少逐轮来源的旧任务省略此提示。
- 用户确认所选的一项计划后，界面从服务端回执显示保存结果。保存超时先核对原操作。练后由本人选择完成状态、填写用时和感受，历史分别显示计划及实际反馈。
- 「训练」支持选动作、相机或相册、上传跟踪、姿态观察及回放和校正。相机权限被拒或内嵌能力不可用时提供系统拍摄和相册。离开训练页或隐藏应用会释放前端相机。
- 手动训练、健康文件导入、遮挡或低置信度按各自状态展示。实际训练和观察结果可保存并编辑，原计数和本人校正值分别显示。媒体删除或过期时保留可查看的结构化记录。

## PWA 与隐私

浏览器首次打开后由服务端签发 HttpOnly 访客 Cookie，空间按访客隔离。`manifest.webmanifest` 及主屏幕图标支持独立窗口。Service Worker 只缓存明确列入清单的同源静态文件。API、私人媒体、查询变体和重定向不进入应用静态缓存。离线时保留未提交文本，回执结果以联网后的服务端核对为准。

用 iPhone 的 Safari 打开当前 HTTPS 预览，点「分享」并选择「添加到主屏幕」，再从桌面图标启动。Safari 页签与主屏幕应用各自验证刷新和继续。相机、旋转、软键盘和独立窗口行为在 iPhone 真机上记录。

## 回归入口

使用隔离实例和临时数据。阶段验收用 `tests/test_frontend_stage31.cjs`，核心异常用例用 `tests/test_prd_v111.cjs`。设置 `PIVOT_UI_ORIGIN` 为隔离回环地址，`NODE_PATH` 指向可用的 Playwright 安装。截图目录由 `PIVOT_UI_EVIDENCE_DIR` 指定。正式交付材料使用示例计划，视频测试仅保存汇总。

V1.1.2 的逐轮来源与降级验收用 `tests/test_prd_v112.cjs`。将 `PIVOT_RULES_ORIGIN` 指向隔离规则实例，将 `PIVOT_MODEL_ORIGIN` 指向已经就绪的本地模型实例。
